# Mulago Eternal Life Gospel Church Songbook — Version 1.0

This is an offline-first installable web app (PWA).

Contents:
- English: 479 hymns
- Luganda: 222 hymns
- Offline search and hymn reader
- Favourites saved on the device
- Font size controls
- Official YouTube channel: https://www.youtube.com/@eternallifegospelchurch7708

## Install using an Android phone
1. Upload this folder to a static web host such as GitHub Pages, Netlify, or another HTTPS host.
2. Open the website in Chrome on Android.
3. Choose the browser menu → Add to Home screen / Install app.
4. Open the installed app once while online so the offline cache is created.
5. After that, the hymn database works without internet.

The sermon section opens the church’s official YouTube channel and requires internet.
